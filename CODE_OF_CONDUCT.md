# Code de conduite

Komolu doit rester un lieu accueillant pour contribuer, apprendre et demander de l'aide.

- Discute les idées et le code avec respect ; les désaccords sont possibles sans attaque personnelle.
- Accepte les différences d'expérience, de langue, d'identité et de disponibilité.
- Évite insultes, harcèlement, discriminations, menaces et divulgation de données privées.
- Demande avant de publier les informations personnelles d'autrui.
- Privilégie des retours concrets et laisse chacun corriger une erreur.

Ces règles s'appliquent aux issues, pull requests et autres espaces officiels du projet. Les mainteneurs peuvent modifier ou retirer un contenu, fermer une discussion ou restreindre une participation lorsque nécessaire, en expliquant leur décision lorsque cela respecte la confidentialité des personnes concernées.

Pour signaler un problème sans exposer de détails privés, contacte un mainteneur par un canal privé qu'il a rendu public sur son profil GitHub. Si aucun canal n'est disponible, demande simplement un contact dans une issue, sans identifier publiquement les personnes concernées. Aucune procédure ne garantit une disponibilité permanente.
